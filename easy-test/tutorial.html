Exploring Glowworm Observations with Tourism and Weather Data

Introduction

The ecotourism package contains wildlife occurrence data, tourism data, and daily weather data for Australia.

In this tutorial, we will investigate glowworm observations in the Derwent Valley region of Tasmania during November 2018.

We will practice joining three datasets:

  • glowworms — wildlife occurrence records
  • weather — daily weather observations
  • tourism_quarterly — quarterly tourism trips

The scientific name of the glowworm in this example is Arachnocampa tasmaniensis.

library(ecotourism)

Because weather observations are recorded by both station and date, we can join the occurrence and weather datasets using ws_id and date.

glow_weather <- merge(
  glowworms,
  weather,
  by = c("ws_id", "date")
)

We can then select the observation from the Derwent Valley example.

derwent_glowworm_weather <- glow_weather[
  glow_weather$ws_id == "949630-99999" &
  glow_weather$date == as.Date("2018-11-28"),
]

Joining with tourism data

Putting the three datasets together

We can now connect the information from the three datasets:

Dataset Information
Occurrence Arachnocampa tasmaniensis observed on 28 November 2018
Weather 16.45°C mean temperature and 42 mm rainfall
Tourism 6.3322 thousand holiday trips in Derwent Valley during Q4 2018

This example demonstrates how wildlife occurrence records can be combined with weather and tourism information to explore conditions associated with wildlife observations.

Key learning points

This exercise demonstrates three important data-wrangling operations:

  1. Joining occurrence and weather data using ws_id and date.
  2. Connecting a weather station to a tourism region using ws_id.
  3. Matching a monthly occurrence to quarterly tourism data by converting November to Q4.

The different time scales are important: occurrence and weather data are daily, while tourism data are quarterly.
